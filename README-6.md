# Suflet Cald — Rugăciuni Sfinte

Site personal Eu Floryan, gata pentru GitHub Pages.

## Cum îl pui pe GitHub Pages (5 minute)

### Opțiunea 1: Prin browser (cel mai simplu)

1. Mergi pe **github.com** → loghează-te cu contul tău `flo7901`
2. Click **"+"** sus-dreapta → **"New repository"**
3. Nume repo: `suflet-cald` (sau orice nume vrei)
4. Bifează **"Public"** + bifează **"Add a README file"**
5. Click **"Create repository"**
6. Click **"Add file"** → **"Upload files"**
7. Trage cele 3 fișiere: `index.html`, `manifest.json`, `sw.js`
8. Adaugă și logo-ul tău cu numele `logo.png` (cel cu file 3933.png)
9. Click **"Commit changes"**
10. Mergi la **Settings** → **Pages** (în meniul stânga)
11. La "Source" alege: **Deploy from a branch**
12. Branch: **main** / Folder: **/ (root)** → **Save**
13. Așteaptă 1-2 minute → site-ul va fi live la:
    **https://flo7901.github.io/suflet-cald/**

### Opțiunea 2: Domeniu propriu

După ce site-ul e live, poți cumpăra un domeniu (ex. `sufletcald.ro` ~10€/an) și să-l conectezi:
- În GitHub: Settings → Pages → Custom domain → tastezi `sufletcald.ro`
- La furnizorul domeniului: setezi DNS-ul către GitHub Pages

## Ce trebuie să modifici personal

### 1. Formular „Cere o rugăciune"
În `index.html`, caută `YOUR_FORM_ID` și înlocuiește cu ID-ul tău Formspree:
- Creează cont gratuit pe **formspree.io**
- Adaugă un nou form pentru email-ul `contact@eufloryan.com`
- Copiază ID-ul (ex: `xyzabc123`) și înlocuiește în cod

### 2. Logo
Adaugă logo-ul tău `3933.png` în repo cu numele **`logo.png`**.

### 3. Mărturii reale
În `index.html`, caută secțiunea "MARTURII" și înlocuiește cele 3 mărturii cu unele reale.

### 4. Newsletter
Acum doar afișează mesaj de mulțumire. Pentru emails reale, conectează cu Brevo:
- Cont gratuit pe **brevo.com** (300 emails/zi gratis)
- Înlocuiește `onsubmit` cu codul lor de formular
